# Otium Mobile (Otium Reader)

قارئ PDF أصيل، خفيف، وسريع لأندرويد — **100% أوفلاين وبدون أي تتبع**.

## المزايا الرئيسية (`v3.1.0`)
- **محرك قراءة PDF أصيل** مع كاش مقيد بالذاكرة (KB-bounded `LruCache`) وتحميل مسبق للصفحات وإعادة تصيير عالي الدقة عند التكبير.
- **بحث صرفي عربي فائق السرعة في Rust (`otium-core`):** يدعم البحث بالجذر وتجاهل التشكيل والتطويل مع نتائج تدريجية (Streaming Search).
- **تظليل النصوص وحفظها في SQLite** مع تضمين التظليلات تلقائياً عند التصدير أو المشاركة (`DocumentExporter`).
- **تنظيم المكتبة:** مجلدات مخصصة (`folder`)، فرز (الأحدث / أبجدي)، تحديد متعدد، ودمج ملفات الـ PDF (`PdfMerger`).
- **خصوصية كاملة:** بدون كاميرا، بدون خدمات Google، وبدون تحليلات أو تتبع.

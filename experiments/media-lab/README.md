# مختبر الوسائط في Otium

تجربة مستقلة على فرع `codex/media-lab` مبنية فوق 1.9.14. لا تغيّر تطبيق القراءة أو البث المنشور، ولا تُنسخ إلى GitHub Pages بواسطة بناء الإصدار الأساسي.

## التجربة الآن

من مجلد المشروع شغّل:

```powershell
npm run lab:media
```

ثم افتح [المختبر المحلي](http://127.0.0.1:5188/). زر **تشغيل فيديو الاختبار** يفتح مقطعاً مولّداً محلياً، مدته أربع ثوانٍ، بحركة وصوت اختباري. اضغط تشغيل لبدء الصوت والفيديو.

| النوع | الموجود في النموذج | الحدود |
|---|---|---|
| MP4 / WebM / MOV / MKV / OGV | مشغّل محلي، تقديم، إيقاف، سرعة وكتم | الترميز يحدد نجاح التشغيل؛ الامتداد وحده لا يكفي |
| MP3 / WAV / M4A / OGG / FLAC | صوت محلي مع مساحة شرح | يعتمد على مفكك الترميز في المتصفح |
| PNG / JPEG / WebP / GIF / AVIF | عرض بالحجم المناسب مع قلم متجهي | الشرح مؤقت؛ لا يحفظ أو يصدّر حالياً |
| PDF | عرض صفحات وقلم | قارئ مختبر بسيط، لا يحل محل قارئ Otium الكامل؛ لا إدخال كلمة مرور |
| TXT / MD | عرض نصّي آمن | Markdown يعرض كنص، بلا HTML أو تنفيذ |
| PPT / PPTX / PPS / PPSX | إرشاد وتجربة التقاط نافذة المحرك الأصلي | **لا يوجد فتح تفاعلي مباشر للملف** |
| رابط تضمين PowerPoint من OneDrive | عارض Microsoft داخل مساحة Otium بعد إدخال الرابط والضغط على فتح | يحتاج الإنترنت وملفاً مستضافاً مسبقاً؛ لم يُختبر بعرض حقيقي في هذه البيئة |
| DOC / DOCX / XLS / XLSX | إرشاد لالتقاط نافذة Word أو Excel | **لا يوجد تحليل أو فتح مباشر لهذه الملفات** |

عند اختيار «شرح اللقطة» تتوقف معاينة الفيديو، وتتاح الكتابة فوقها. «إنهاء الشرح» يمسح الشرح المؤقت. أثناء التقاط نافذة، يتوقف الفيديو في المعاينة فقط؛ نافذة المصدر قد تستمر بالتشغيل. لا يوجد حفظ تعليقات أو مزامنة هاتف أو نقل وسائط عبر الشبكة في هذا النموذج.

«إخفاء الأدوات» يترك مساحة العرض وزر إظهار الأدوات. تغيير حجم مساحة العرض يحافظ على عنصر المشغل ونسبة أبعاد المحتوى. وضع ملء الشاشة يعتمد على دعم المتصفح وتفاعل المستخدم.

## اختبار PowerPoint بالحركات والفيديو

1. افتح العرض في PowerPoint على حاسب، وشغّل عرض الشرائح في نافذة.
2. في المختبر اضغط «التقاط نافذة عرض»، واختر نافذة الشرائح في منتقي المتصفح.
3. اختبر حركة دخول وخروج، حركة تبدأ بالنقر، انتقالاً، وفيديو مضمناً بصوت.
4. تحكم بالشرائح من PowerPoint. النقر داخل معاينة Otium لا يُرسل إلى نافذة المصدر.
5. استخدم زر الإغلاق أو إيقاف المشاركة في المتصفح. يجب تحرير مسارات الالتقاط فوراً.

اختيار نافذة Otium نفسها يسبب انعكاساً متكرراً. مشاركة الصوت تعتمد على المتصفح والمصدر المختار. معاينة الالتقاط مكتومة افتراضياً لمنع تكرار صوت المصدر. دعم الالتقاط ليس متاحاً على كل المتصفحات أو الهواتف. هذه أداة لدراسة الجودة، وليست الحل النهائي للتحكم الموحد.

لم يُعثر على PowerPoint أو LibreOffice في مسارات البرامج المعتادة أو تسجيل PowerPoint COM على بيئة العمل؛ لذلك لم يتم اختبار عرض PPTX حقيقي هنا.

يوجد أيضاً خيار **PowerPoint من OneDrive**: الصق عنوان `src` من كود التضمين الرسمي، بصيغة `https://onedrive.live.com/embed?resid=…` ثم اضغط فتح عبر Microsoft. يدعم النموذج هذا العنوان المحدد فقط؛ روابط المشاركة المختصرة وروابط SharePoint وكود iframe الكامل غير مقبولة حالياً. لا يحتفظ التطبيق بالرابط في التخزين ولا يسجله. روابط التضمين قد تمنح الوصول لمن يملكها؛ راجع صلاحيات الملف في OneDrive، ولا تنشر الرابط إذا كان العرض خاصاً. التحكم داخل هذا الإطار تابع لعارض Microsoft، وشرح Otium فوقه ومزامنته إلى الهاتف غير منفّذين.

## الحماية والعزل

- لا رفع ملفات أو إضافة تبعيات جديدة. عارض Microsoft الخارجي خيار صريح لا يُفتح إلا بعد إدخال رابط تضمين جاهز والضغط على فتح.
- الملفات المحلية تستخدم Blob URLs وتُحرّر عند الإغلاق أو الاستبدال. إغلاق المعاينة يوقف التشغيل ويلغي الالتقاط المتأخر.
- حد النص 2 MiB، الصور وPDF نحو 80 MiB، والوسائط 2 GiB. هذه حدود أولية وليست ضماناً لاستهلاك الذاكرة عند فك ملفات معقدة.
- لا تنفيذ HTML أو SVG أو ملفات ماكرو. نصوص الملفات تعرض عبر React كنص عادي.
- سياسة CSP تحصر اتصالات التطبيق بالموارد المحلية، وتسمح بإطار OneDrive الرسمي فقط بعد اختياره. الإطار نفسه يتصل بخدمات Microsoft. ملفات خطوط وWASM وCMap الخاصة بـPDF محلية.
- خادم التجربة يستمع إلى `127.0.0.1` فقط؛ لا يتيح مشاركة ملفاتك على الشبكة المحلية.
- بناء التجربة يكتب إلى `dist-media-lab` فقط. موارد PDF المولّدة في `.generated-assets` لا تدخل Git.

## التحقق

```powershell
npm run lab:media:test
npm run lab:media:build
npx oxlint experiments/media-lab
```

نجح 23 اختباراً آلياً للنموذج: إلغاء الالتقاط المتأخر، إيقاف المسارات، تحرير URLs، تبديل الملفات، عرض النص بأمان، إخفاء الأدوات وإظهارها، المحافظة على المصدر عند تدوير المساحة، إعادة تشغيل تأثيرات React، إنهاء ضربات القلم وإلغاؤها، وحصر عارض Microsoft بالرابط الرسمي وفتحه بطلب صريح وإغلاقه. نجحت أيضاً اختبارات التطبيق الأساسي البالغ عددها 201 وفحص TypeScript. هذه اختبارات DOM ودورة حياة؛ لا تثبت فك الترميز أو الصوت أو مشاركة الشاشة على جهاز حقيقي. تعذّر تشغيل أداة فحص الواجهة بسبب خطأ في نواة الأداة، لذلك بقي الفحص البصري والتشغيل الفعلي على الهاتف والسبورة مطلوبين.

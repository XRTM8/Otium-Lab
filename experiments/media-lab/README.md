# مختبر الوسائط المحلي في Otium

فرع تجريبي مستقل: `codex/media-lab`. لم يُدمج في التطبيق الرئيسي 1.9.15. نقطة انطلاق الفرع هي 1.9.14، وتعديلات هذا المختبر محصورة في مجلده وأوامر تشغيله. لا ترفع التجربة الملفات إلى خدمة خارجية، ولا تحتوي عارض Office مضمناً أو التقاط نافذة برنامج آخر.

## التشغيل

```powershell
npm run lab:media
```

افتح [المختبر المحلي](http://127.0.0.1:5188/). توجد معاينة بناء منفصلة عند تشغيل:

```powershell
npm run lab:media:build
npx vite preview --config experiments/media-lab/vite.config.ts --port 5190 --strictPort
```

ثم افتح [معاينة البناء](http://127.0.0.1:5190/). الخادم محلي على الحاسب نفسه؛ لا يتيح الوصول من الهاتف عبر الشبكة حالياً.

## الموجود فعلياً

| النوع | الإمكانية | الحدود |
|---|---|---|
| فيديو MP4 / WebM / MOV / MKV / OGV | تشغيل، إيقاف، تقديم، سرعة، كتم وملء الشاشة | نجاح التشغيل يعتمد على ترميز الملف والمتصفح، لا على الامتداد وحده |
| صوت MP3 / WAV / M4A / OGG / FLAC | تشغيل محلي ومساحة شرح | يعتمد على مفكك الترميز في المتصفح |
| PNG / JPEG / WebP / GIF / AVIF | عرض بنسبة الأبعاد الأصلية وشرح | الشرح مؤقت |
| PDF | عرض صفحات وتقليب وقلم | قارئ تجريبي بسيط؛ لا يحل محل قارئ Otium الكامل ولا يدعم إدخال كلمة مرور |
| TXT / MD | نص عادي آمن | لا تحويل Markdown إلى HTML أو تنفيذ محتواه |
| PPTX / PPSX | شرائح ثابتة محلية مع تقليب وشرح | نصوص، صور PNG/JPEG/GIF/WebP، أشكال أساسية، مجموعات، وبعض وراثة القالب؛ المعاينة تقريبية |
| PPT / PPS القديم | غير مدعوم | يحتاج نسخة PPTX أو PDF |
| DOCX / DOC / XLSX / XLS | غير مدعوم بعد | يظهر تنبيه واضح؛ لا رفع أو تشغيل برنامج خارجي |

الحركات والفيديو والصوت داخل شرائح PPTX لا تُشغّل. الفيديو المستقل يُفتح مباشرة في المشغّل. الجداول والمخططات وSmartArt والأشكال الحرة والخطوط الخاصة وبعض القص والتأثيرات غير مدعومة بدقة؛ تظهر إشارة عند اكتشاف عناصر لا يمكن عرضها. لا نعد بمطابقة PowerPoint الكاملة.

«شرح اللقطة» يوقف الفيديو ويتيح قلماً متجهياً فوق اللقطة. «إنهاء الشرح» يمسح الشرح المؤقت. تغيير الشريحة يمسح طبقة الشرح الحالية. لا يوجد حفظ أو تصدير للتعليقات في هذا النموذج. «إخفاء الأدوات» يخفي الرأس والتذييل والتحكم ويُبقي زر الإظهار.

## الحماية وحدود الموارد

- لا خدمات عرض خارجية، ولا iframe، ولا رفع ملفات تلقائي، ولا إضافة اعتماديات جديدة.
- فك ZIP يتم محلياً عبر DecompressionStream بصيغة deflate-raw؛ المتصفحات القديمة التي لا تدعمه تعرض سبب الفشل.
- حد ملف PPTX هو 40 MiB و200 شريحة. ZIP محدود بعدد 2048 جزءاً، وحجم معلن إجمالي 96 MiB، وجزء واحد 16 MiB، وXML واحد 2 MiB. حجم فك الضغط الفعلي مقيد أيضاً وتُفحص CRC.
- حد الشريحة 500 عنصر و100 ألف محرف نصّي و32 MiB لصورها، وعمق المجموعات 8. هذه حدود للبيانات؛ لا تضمن استهلاك ذاكرة ثابتاً بعد فك الصور المعقدة.
- تُرفض المسارات المشبوهة والأرشيفات المشفرة وصيغ ZIP غير المدعومة وDTD/ENTITY. تُتجاهل الروابط والعلاقات الخارجية.
- لا تشغيل ماكرو أو HTML أو SVG مرفوع. النص يُنشأ عبر React، والصور المسموح بها من داخل الملف فقط.
- تُحرّر Blob URLs عند إغلاق الملف أو تبديل الشريحة، وتُلغى القراءات القديمة كي لا تستبدل المصدر الحالي.
- CSP تمنع الإطارات والاتصالات الخارجية. ملفات الخطوط وPDF وWASM محلية. بناء التجربة يكتب إلى `dist-media-lab` فقط.

## التحقق المنجز

```powershell
npm run lab:media:test
npm run lab:media:build
npx oxlint experiments/media-lab
```

نجح **29 اختباراً آلياً** للمختبر، والبناء وفحص المصدر. تغطي الاختبارات سلامة ZIP والضغط والروابط والإلغاء، ترتيب الشرائح ووراثة القالب والمجموعات والصور، تحرير موارد الشرائح، تغيير الأبعاد دون فقد المصدر، والنص والوسائط وأدوات الإخفاء.

في متصفح Brave/Chromium فعلي على Windows، بملف شخصي معزول، تم التحقق من:

- عرض ملف Open XML مولّد للاختبار يحتوي معرفات شرائح رقمية، نصاً عربياً وإنكليزياً وصورة وشكلاً مجمّعاً.
- تقليب الشرائح والبقاء في الشريحة الثانية عند تغيير أبعاد محاكاة الهاتف إلى الأفقي.
- تشغيل مقطع H.264/AAC مولّد محلياً: 960×540، أربع ثوانٍ، وفك 96 إطاراً.
- إيقاف مشغّل نشط عند بدء الشرح، ثم إخفاء وإظهار الأدوات وإغلاق الملف.
- عدم وجود iframe أو موارد تطبيق من أصول خارجية، وعدم تسجيل استثناءات JavaScript غير معالجة خلال هذه التجربة.

هذا اختبار لمتصفح حاسب بمحاكاة مقاسات الهاتف، وليس اختباراً لهاتف Android أو سبورة فعلية، ولا مقارنة بصرية مع PowerPoint الأصلي. يبقى اختبار ملفات مدرسية حقيقية متنوعة مطلوباً.

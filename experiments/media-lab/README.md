# محركات الوسائط في Otium Lab

الواجهة الأساسية أصبحت نسخة Otium الكاملة: استخدم أوامر التشغيل في README.md في جذر المستودع، وافتح الملفات من مكتبة Otium نفسها.

هذا المجلد منصة اختبار صغيرة للمحركات المشتركة الموجودة في src/media، وليس الموقع المنشور.

```powershell
npm run lab:media
npm run lab:media:test
npm run lab:media:build
```

PPTX/PPSX يعرض شرائح ثابتة تقريبية، والفيديو المستقل يستخدم مفكك ترميز المتصفح. بث الصيغ الجديدة لم يُنفذ بعد. حفظ الشرح ونسخه واستعادته متاحة داخل تطبيق Labs الكامل؛ واجهة فحص المحركات هنا تستخدم شرحاً مؤقتاً. راجع STUDY.md لاتجاه العمل وحدود الصيغ.
